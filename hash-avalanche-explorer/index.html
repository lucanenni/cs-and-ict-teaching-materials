L'effetto valanga

Cambia anche un solo carattere in un testo, e il suo "hash" diventa irriconoscibile

Come funziona?

  • • Una funzione hash trasforma un testo di lunghezza qualsiasi in una sequenza di lunghezza fissa (qui, 64 cifre esadecimali = 256 bit), sempre la stessa per lo stesso testo in ingresso.
  • • Una buona funzione hash ha l'effetto valanga: anche la più piccola modifica al testo in ingresso cambia completamente il risultato, in modo imprevedibile.
  • • Per questo un hash si usa per verificare l'integrità di un file o di un messaggio: se anche un solo bit viene alterato (per errore o di proposito), l'hash cambia radicalmente e la manomissione si nota subito.

Oltre a verificare l'integrità dei file (i siti di download spesso pubblicano l'hash di un programma, così puoi controllare che il file scaricato non sia stato alterato), gli hash sono alla base di come i siti memorizzano le password in modo sicuro: non salvano mai la password in chiaro, ma solo il suo hash. Quando fai login, il sito calcola l'hash di quello che scrivi e lo confronta con quello salvato — così, anche se il database venisse rubato, le password vere non sarebbero direttamente leggibili. Sono anche fondamentali per le "catene" di blocchi usate dalle criptovalute, dove ogni blocco contiene l'hash del blocco precedente.
