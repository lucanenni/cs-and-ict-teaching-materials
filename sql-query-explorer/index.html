Cosa capisce questo motore?

  • • SELECT colonna1, colonna2 FROM tabella oppure SELECT * per tutte le colonne.
  • • WHERE colonna OPERATORE valore, con = != <> < > <= >=, anche incatenate con AND. I testi vanno tra apici: '5A'.
  • • JOIN altratabella ON tabella1.colonna = tabella2.colonna per unire le due tabelle riga per riga dove la condizione è vera.
  • • ORDER BY colonna, opzionalmente seguito da ASC o DESC.

Nell'ordine: prima carica tutte le righe della tabella in FROM; se c'è un JOIN, confronta ogni riga della prima tabella con ogni riga della seconda e tiene solo le coppie che soddisfano la condizione ON (un prodotto cartesiano filtrato, il modo più semplice — anche se non il più efficiente — di fare un join); poi scarta le righe che non soddisfano il WHERE; poi ordina, se richiesto; solo alla fine sceglie quali colonne mostrare, in SELECT. È anche l'ordine logico con cui un vero database SQL valuta una query, anche se la sintassi la scrive con SELECT per primo.
