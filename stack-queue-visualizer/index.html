Come funziona?

    La pila delle chiamate di ogni programma (visibile anche nel progetto "Albero della ricorsione" di questa raccolta) è, letteralmente, una pila: ogni funzione chiamata viene "impilata" sopra la precedente, e quella che finisce per prima è sempre l'ultima chiamata (LIFO). Anche il tasto "Annulla" (Ctrl+Z) di un editor funziona così: ogni azione va in cima a una pila, e annullare toglie sempre l'ultima. Le code invece si usano ovunque serva rispettare l'ordine di arrivo: una stampante che processa i documenti nell'ordine in cui sono stati inviati, o un sistema che gestisce le richieste di un sito web una alla volta, nell'ordine in cui arrivano (FIFO).
